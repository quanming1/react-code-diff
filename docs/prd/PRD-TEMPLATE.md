## 1. 背景与目标

- **背景**：为什么要做（解决什么问题；消费方是谁）。
- **目标**：完成后的可交付状态（一句话）。
- **非目标**：明确不做的事（防范围蔓延）。

## 2. 需求范围

### 2.1 功能需求

每条可勾选、可验收：

- [ ] FR1：描述（含输入/输出/行为）

### 2.2 非功能需求

- 性能：…
- 兼容性：…（对外 props 的破坏性变更必须显式声明）

## 3. 技术方案

- 模块设计（文件 / 职责）
- 关键数据结构 / props 定义
- 依赖选型

## 4. 接口定义

- 导出 API / props / 事件（本库是 npm 组件库，对外 API 即接口契约）

## 5. 验收标准

每条可执行（命令 / 断言 / 勾选）：

- [ ] AC1：执行 `xxx` 应得到 `yyy`
- [ ] AC2：vitest 全部通过

- 单元测试覆盖点（src/**/__tests__/，node 环境纯逻辑）
